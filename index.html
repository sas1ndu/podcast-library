    What this release does

    Local playback, cloud upload, shareable players, and a browser-local subject library. Compression, automatic transcription, and shared cloud collections are not part of this release.

    Connection settings

    The site default comes from config.js. An override below changes only this browser, not everyone else's site.

    Use the base address only, without /health or /upload. Leave empty for local-only mode.

    API addresses are public, not secrets. Never put R2 access keys or Cloudflare API tokens in this frontend.

    Deleting a subject moves its recordings to Unsorted. It does not delete audio.
